Join the new and growing Drasi community and help shape the future of this project. There are several ways to collaborate and contribute to Drasi:

* **Start or join a discussion**: The Drasi <a href="https://aka.ms/drasidiscord" target="_blank" rel="noopener noreferrer">Discord community</a> is the quickest place to ask questions, share feedback, and show what you are building with Drasi.
* **Contribute code or docs**: Visit our <a href="https://github.com/drasi-project" target="_blank" rel="noopener noreferrer">GitHub organization</a> to improve the platform, documentation, or build a new Source or Reaction for the ecosystem.
* **Read the contribution guide**: The <a href="https://github.com/drasi-project/docs/blob/main/CONTRIBUTING.md" target="_blank" rel="noopener noreferrer">Contributing guide</a> explains how to propose changes, run the docs locally, and participate in the project.
* **Follow the code of conduct**: The <a href="https://github.com/drasi-project/docs/blob/main/CODE_OF_CONDUCT.md" target="_blank" rel="noopener noreferrer">Code of Conduct</a> sets the expectations for an inclusive, respectful community.
* **Watch the project and docs**: Follow the <a href="https://github.com/drasi-project/docs" target="_blank" rel="noopener noreferrer">documentation repository</a>, <a href="https://github.com/drasi-project" target="_blank" rel="noopener noreferrer">GitHub org</a>, and the community social channels to keep up with updates and opportunities to contribute.
